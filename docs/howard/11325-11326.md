## 2. dev：問題釐清／解決方法

原本只註冊 portable avg_pool2d。新增兩個薄 wrapper 與共用 `avg_pool_util.h`，先檢查參數及輸出 shape，再逐 window 累加有效輸入。ceil mode 不產生完全落在右側 padding 的 window；包含 padding 時，分母只計實際 padded 範圍。Half／BFloat16 用 float 累加；Long 保留整數除法語意。3D 的 divisor_override 可為負數但不能為零，且各空間軸不得小於 kernel。

| 檔案 | 變更 |
| --- | --- |
| kernels/portable/cpu/op_avg_pool1d.cpp、op_avg_pool3d.cpp | schema 對應入口 |
| kernels/portable/cpu/util/avg_pool_util.h、targets.bzl | 共用 shape／邊界／累加邏輯及 Buck header export |
| kernels/portable/functions.yaml | 兩個 out operators 註冊 |
| kernels/test/op_avg_pool1d_test.cpp、op_avg_pool3d_test.cpp | 69 個正式回歸測試 |
| kernels/test/CMakeLists.txt、targets.bzl；shim_et/xplat/executorch/build/build_variables.bzl 與 kernels/portable/op_registration_util.bzl | CMake／Buck 測試與 kernel 來源登錄 |

Diff review 已檢查預設 stride、負 stride、padding 長度、整數截斷、ceil 邊界、半精度累加、輸出 rank 與 registration；既有 avg_pool2d 實作未變更。

## 3. regression test／解決後 Demo

```sh
python3 docs/howard/avg_pool_validation.py
/tmp/avg-build/test
SANITIZE=1 AVG_BUILD=/tmp/avg-asan-build python3 docs/howard/avg_pool_validation.py
ASAN_OPTIONS=detect_leaks=0:handle_segv=0 timeout 30s /tmp/avg-asan-build/test
```

Fixed：69/69 passed，exit 0；ASan/UBSan：69/69 passed，exit 0。Sanitizer 儀器化範圍為新 kernels 與 tests；既有 runtime libraries 未重建儀器化。初次 ASan 使用預設 signal handler 發生重複 DEADLYSIGNAL，改用 handle_segv=0 後成功；沒有停用 address／undefined-behavior instrumentation。

額外數值查核：Python random seed 11325、torch seed 11326，生成每個算子 80 個 float／double／long 對照案例，涵蓋不同 batch、各軸 kernel／stride／padding、ceil、分母選項。含正式案例共 229/229 passed。生成器 `/tmp/gen-avg-differential.py`，輸出 `/tmp/avg-differential{1,3}.cpp`，log `/tmp/avg-differential.log`；這些是本機補充實驗，正式 fixtures 在 repo 測試檔。

選擇性 codegen 僅含兩個新算子，編譯 generated registry 與新 kernels 後執行 `/tmp/avg-reg/smoke`：`avg_pool1d registered=1, avg_pool3d registered=1`，exit 0。
既有 avg_pool2d 測試：`portable_kernels_test --gtest_filter='OpAvgPool2DOutTest.*'`，3/3 passed。
clang-format 與 git diff --check 通過。
