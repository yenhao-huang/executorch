## Summary

ExecuTorch has a portable `_adaptive_avg_pool2d.out` kernel but no
`adaptive_avg_pool1d.out`. This adds the portable kernel for batched
`(N, C, L)` and unbatched `(C, L)` inputs, matching the ATen CPU schema
`adaptive_avg_pool1d.out(Tensor self, int[1] output_size, *, Tensor(a!) out)`.

The issue has no comments, no assignee and no linked or community PR; upstream
main has neither `op_adaptive_avg_pool1d.cpp` nor a `functions.yaml` entry.

## Algorithm

```text
Validate dtype, dim order, input rank (2D or 3D) and non-empty length L.
Require output_size to have exactly one non-negative element O.
Resize the output to the input shape with the last dimension replaced by O.

For each batch/channel row:
    For each output position i in [0, O):
        start = floor(i * L / O)
        end = ceil((i + 1) * L / O)
        Sum input[start:end] in the accumulator type
        (float for Half/BFloat16, the input type otherwise).
        Store sum / (end - start).
```

Window bounds use integer arithmetic instead of the float-based helpers in
`op__adaptive_avg_pool2d.cpp`, so they stay exact for large lengths.
